# 다음 작업

## 기획 기준

첨부 기획서 《어제의 지도》 게임 기획 정리를 현재 문서 작업의 기준으로 삼는다. 구현은 기존 씬, 프리팹, 스크립트를 확인한 뒤 단계적으로 맞춘다.

현재 구현에 반영된 기준:

- Scavenge는 `4개 운반 → 벙커 보관 → 재파밍 → 시간 안에 본인도 벙커 진입` 구조를 사용한다.
- 메인 일기는 아이템 사용 UI가 아니라 상태, 스토리, 이벤트 결과, 탐사 결과를 보여주는 기록 UI다.
- 아이템별 정확한 수량 확인과 사용은 Shelter 창고에서 처리한다.
- 판단 기록 책은 일반 생존 물자 총 개수에 포함하지 않는다.
- 날짜 자체는 엔딩 조건이 아니며 구조신호·합류 최종 선택 또는 생존 실패 조건이 게임 종료를 호출한다.
- 감염과 좀비화 사망 시스템은 사용하지 않는다.
- 라디오 확보 방식은 아직 확정되지 않았다.
