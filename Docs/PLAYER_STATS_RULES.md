# 플레이어 스탯 시스템 규칙

최종 갱신: 2026-08-03

이 문서는 플레이어 생존 스탯 판정의 기준 문서다. 구현 시 이 문서를 우선 기준으로 삼는다.

플레이어는 생존 과정에서 체력, 배고픔, 갈증, 정신력의 총 4가지 스탯을 관리한다.

각 스탯은 서로 독립적으로 작동한다. 특정 스탯이 감소하거나 0이 되더라도 다른 스탯이 대신 감소하거나 피해를 받지 않는다.

예를 들어 배고픔이나 갈증이 0이 되어도 체력이 자동으로 감소하지 않으며, 각 스탯에 정해진 별도의 위험 상태와 페널티가 적용된다.

감염 스탯과 좀비화 사망 시스템은 사용하지 않는다.

## 1. 체력

체력은 플레이어의 직접적인 생존 상태를 나타내는 스탯이다.

탐사 중 부상, 좀비나 약탈자의 공격, 위험한 이벤트 선택 등의 결과로 감소할 수 있으며, 구급상자를 사용해 회복할 수 있다.

체력이 0이 되더라도 즉시 사망하지 않는다. 체력 0 상태로 다음 날 아침을 맞으면 사망하는 대신 빈사 상태에 진입하며, 그날 잠들기 전까지 마지막 회복 기회를 얻는다.

빈사 상태에서도 탐사와 일반 이벤트를 포함한 모든 행동을 진행할 수 있다. 다만 몸 상태가 좋지 않으므로 탐사에서 얻는 아이템 수와 희귀 아이템 확률이 감소하고 빈손 귀환 확률이 증가한다.

빈사 상태가 된 날 체력을 1 이상으로 회복하면 빈사 상태와 사망 판정이 해제된다. 체력이 0인 채로 잠들면 `마지막 생존 기록`의 치명적인 부상 사망 엔딩으로 진입한다.

- 체력 0 도달 당일에는 즉시 사망하지 않는다.
- 체력은 0보다 낮아지지 않고 0으로 고정한다.
- 체력 0 도달 당일에는 치료가 필요하다는 위험 경고를 표시한다.
- 체력 0 상태로 다음 날 아침에 진입하면 빈사 상태가 된다.
- 빈사 상태에서도 탐사, 일반 이벤트, 인벤토리 사용과 회복 아이템 사용이 가능하다.
- 빈사 상태에서는 탐사 획득 개수와 희귀 아이템 확률이 감소하고 빈손 귀환 확률이 증가한다.
- 구급상자는 빈사 상태에서도 획득 가능하며 병원은 여전히 가장 높은 획득 가능성을 가진다.
- 빈사 상태가 된 날 잠들기 전까지 체력을 1 이상으로 회복하면 사망 판정이 취소된다.
- 빈사 상태에서 체력 0으로 잠들려고 하면 최종 사망 경고를 표시한다.
- 경고를 확인하고 체력 0으로 잠들면 치명적인 부상 사망 엔딩으로 진입한다.
- 회복 후 다시 체력이 0이 되면 새로운 체력 0 상태로 처음부터 판정한다.
- 배고픔이나 갈증이 0이 되어도 체력이 대신 감소하지 않는다.

체력 사망 판정 예시:

`5일 차 체력 0 도달 -> 6일 차 아침 빈사 상태 -> 6일 차 안에 회복하지 못함 -> 체력 0으로 잠들면 사망`

빈사 상태에서 회복한 경우:

`5일 차 체력 0 도달 -> 6일 차 아침 빈사 상태 -> 6일 차 구급상자 사용 -> 체력 1 이상 회복 -> 빈사 및 사망 판정 해제`

## 2. 배고픔

배고픔은 플레이어의 식량 섭취 상태를 나타내는 스탯이다.

날짜 경과와 생존 활동에 따라 감소하며, 통조림과 같은 음식 아이템을 사용해 회복할 수 있다.

배고픔이 0이 되더라도 당일에는 즉시 사망하지 않으며, 별도의 경고 일기도 나타나지 않는다. 이후 배고픔이 0인 상태로 계속 유지되면 다음 날 아침부터 일기를 통해 위험 상태를 경고한다.

배고픔 사망 판정:

- 배고픔 0 도달 당일: 사망 및 경고 없음
- 다음 날 아침까지 0 유지: 1차 굶주림 경고 일기
- 그다음 날 아침까지 0 유지: 2차 굶주림 경고 일기
- 2차 경고 이후 다음 날 아침까지 0 유지: 굶주림 사망

예시:

`5일 차 배고픔 0 도달 -> 6일 차 1차 경고 -> 7일 차 2차 경고 -> 8일 차 아침 사망`

배고픔이 0이더라도 체력이 대신 감소하지 않는다. 두 차례의 경고가 진행되는 동안 음식을 섭취해 배고픔을 회복하면 사망을 피할 수 있다.

## 3. 갈증

갈증은 플레이어의 수분 섭취 상태를 나타내는 스탯이다.

날짜 경과와 생존 활동에 따라 감소하며, 물 아이템을 사용해 회복할 수 있다.

갈증의 사망 판정 방식은 배고픔과 동일하다. 갈증이 0이 된 당일에는 즉시 사망하지 않으며, 별도의 경고 일기도 나타나지 않는다. 이후 갈증이 0인 상태로 계속 유지되면 다음 날 아침부터 두 차례의 경고 일기가 나타난다.

갈증 사망 판정:

- 갈증 0 도달 당일: 사망 및 경고 없음
- 다음 날 아침까지 0 유지: 1차 탈수 경고 일기
- 그다음 날 아침까지 0 유지: 2차 탈수 경고 일기
- 2차 경고 이후 다음 날 아침까지 0 유지: 탈수 사망

예시:

`5일 차 갈증 0 도달 -> 6일 차 1차 경고 -> 7일 차 2차 경고 -> 8일 차 아침 사망`

갈증이 0이더라도 체력이 대신 감소하지 않는다. 두 차례의 경고가 진행되는 동안 물을 마셔 갈증을 회복하면 사망을 피할 수 있다.

## 4. 배고픔, 갈증 경고 단계 초기화 규칙

배고픔 또는 갈증이 0인 상태에서 경고가 진행되는 도중 음식이나 물을 사용해 해당 스탯을 회복하면, 지금까지 진행된 경고 단계는 즉시 초기화된다.

경고 단계가 초기화된 이후 해당 스탯이 다시 0이 되면 이전 경고 진행 상황을 이어서 계산하지 않는다. 새로운 위험 상태로 판정하며, 다시 0이 된 다음 날 아침부터 항상 1차 경고 일기부터 다시 시작한다.

- 1차 경고 이후 회복하면 경고 단계가 초기화된다.
- 2차 경고 이후 회복해도 경고 단계가 초기화된다.
- 해당 스탯이 1 이상으로 회복되는 순간 사망 진행 판정이 중단된다.
- 회복 후 다시 0이 되면 새로운 0 상태로 판정한다.
- 다시 0이 된 다음 날 아침에는 1차 경고부터 시작한다.
- 이전에 받은 경고 횟수는 다음 위험 상태에 누적되지 않는다.

배고픔 경고 초기화 예시:

`5일 차 배고픔 0 도달 -> 6일 차 1차 경고 -> 6일 차 통조림 섭취 -> 배고픔 회복 및 경고 초기화`

이후 배고픔이 다시 0이 된 경우:

`8일 차 배고픔 0 도달 -> 9일 차 1차 경고 -> 10일 차 2차 경고 -> 11일 차 아침까지 0 유지 시 사망`

갈증 경고 초기화 예시:

`5일 차 갈증 0 도달 -> 6일 차 1차 경고 -> 7일 차 2차 경고 -> 7일 차 물 섭취 -> 갈증 회복 및 경고 초기화`

이후 갈증이 다시 0이 된 경우:

`9일 차 갈증 0 도달 -> 10일 차 1차 경고부터 다시 시작`

배고픔과 갈증의 사망 판정은 해당 스탯을 1 이상으로 회복하면 중단된다. 이후 다시 0이 되면 이전 경고 단계와 관계없이 처음부터 판정한다.

## 5. 배고픔과 갈증이 동시에 0인 경우

배고픔과 갈증은 각각 독립적으로 경고 단계와 사망 날짜를 계산한다.

두 스탯의 사망 조건이 모두 충족된 경우에는 먼저 0 상태에 도달한 스탯을 사망 원인으로 우선 판정한다.

두 스탯이 서로 다른 날짜에 0이 되었다면 먼저 0이 된 스탯의 경고와 사망 판정이 먼저 진행된다.

배고픔과 갈증이 같은 날 동시에 0이 된 경우의 사망 원인 우선순위는 추후 별도로 정한다.

## 6. 정신력

정신력은 재난 상황에서 플레이어가 심리적으로 버틸 수 있는 상태를 나타내는 스탯이다.

외부 사건, 고립, 위험한 탐사 결과, 부정적인 이벤트 선택 등으로 감소할 수 있으며, 인형, 책, 축구공, 기타와 같은 정신력 아이템을 사용해 회복하거나 관리할 수 있다.

정신력이 0이 되더라도 플레이어는 사망하지 않는다. 대신 심리적으로 외부 활동을 감당할 수 없는 상태가 되어 탐사를 진행할 수 없게 된다.

- 정신력 0 도달 시 사망하지 않는다.
- 정신력 전용 사망 엔딩은 없다.
- 정신력 0 상태에서는 탐사할 수 없다.
- 정신력이 0보다 높은 상태로 회복되면 다시 탐사할 수 있다.
- 주요 관리 수단은 인형, 책, 축구공, 기타 등의 정신력 아이템이다.

## 공통 판정 원칙

- 체력, 배고픔, 갈증, 정신력은 각각 독립적으로 판정한다.
- 배고픔이나 갈증이 0이 되어도 체력이 대신 감소하지 않는다.
- 체력 0 당일에는 위험 경고를 표시하고, 다음 날 아침에는 사망 대신 빈사 상태에 진입한다.
- 체력에는 배고픔과 갈증처럼 1차, 2차 누적 경고 단계가 없다.
- 빈사 상태가 된 날 잠들기 전까지 체력을 1 이상으로 회복하면 사망 판정이 취소된다.
- 빈사 상태에서 체력 0으로 잠들면 치명적인 부상 사망 엔딩으로 진입한다.
- 배고픔과 갈증은 두 차례의 일기 경고를 통해 플레이어에게 회복 기회를 제공한다.
- 배고픔과 갈증이 경고 도중 1 이상으로 회복되면 경고 단계는 완전히 초기화된다.
- 회복 후 다시 0이 되면 다음 날 1차 경고부터 새로 시작한다.
- 정신력은 사망 조건으로 사용하지 않고 탐사 가능 여부를 제한하는 스탯으로 사용한다.
- 감염 스탯과 좀비화 사망 시스템은 사용하지 않는다.

## 구현 상태

2026-08-03 기준으로 핵심 판정은 `CharacterStats`, `DayCycleManager`, `BedObject`, `ExplorationManager`에 반영됐다.

- 감염 스탯과 감염 사망 판정은 사용하지 않는다.
- 배고픔과 갈증은 100이 충분한 상태, 0이 고갈된 상태로 표시한다.
- 배고픔과 갈증의 0 상태는 체력을 감소시키지 않는다.
- 0 상태로 다음 아침을 맞을 때 1차, 2차 경고를 순서대로 기록하고 그다음 아침에 사망한다.
- 해당 스탯이 1 이상으로 회복되면 경고 단계와 0 도달 순서를 초기화한다.
- 체력 0 당일에는 즉사하지 않고 다음 아침 빈사 상태가 된다.
- 빈사 상태에서 체력 0으로 잠들면 최종 확인 후 치명상 엔딩으로 진입한다.
- 빈사 상태의 탐사는 위험도와 빈손 확률이 높고, 획득량과 희귀 물자 회수 확률이 낮다.
- 정신력 0은 사망시키지 않고 탐사만 차단한다.
- 경고 기록은 일기장의 메인 일기에서 최근 4개까지 확인할 수 있다.
