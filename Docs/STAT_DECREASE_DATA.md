# 생존 스탯 감소 수치 데이터

최종 갱신: 2026-08-06

이 문서는 현재 구현된 체력, 허기, 갈증, 정신력 감소 수치와 발생 조건을 정리한다. 모든 스탯은 `0~100` 범위로 제한되며, 허기나 갈증이 0이 되어도 체력이 대신 감소하지 않는다.

## 요약

| 발생 조건 | 체력 | 허기 | 갈증 | 정신력 | 비고 |
| --- | ---: | ---: | ---: | ---: | --- |
| 정상 수면 완료 | 0 | -20 | -30 | -10 | 침대 수면 완료 시 1회 적용 |
| 탐사 시작 | 0 | -15 | -10 | 0 | 탐사 성공 여부와 무관 |
| 탐사 실패 후 부상 | -8 또는 -18 | 0 | 0 | 0 | 장비 지참 시 -8, 미지참 시 -18 |
| 탐사 실패 후 공포 | 0 | 0 | 0 | -6 또는 -12 | 장비 지참 시 -6, 미지참 시 -12 |
| 1분기 일반 이벤트 | -5 또는 -10 | 0 | 0 | 주로 -5 | 선택 및 확률에 따라 적용 |
| 2분기 `Q2_SIGNAL_EVT_01` 진행 | 0 | 0 | 0 | -5 | 진행 선택 시 적용 |
| 2분기 `Q2_SIGNAL_EVT_02` 진행 | -5 | -5 | -5 | 0 | 탐사 요구 이벤트 |

일반 배급, 아껴 먹기, 먹지 않기 기능과 관련 증감 수치는 현재 구현에서 제거됐다.

## 수면 감소

정상적인 침대 수면 연출이 완료되면 날짜 변경 전에 다음 수치가 적용된다.

| 스탯 | 감소량 |
| --- | ---: |
| 체력 | 0 |
| 허기 | -20 |
| 갈증 | -30 |
| 정신력 | -10 |

처리 순서는 `수면 감소 -> 야간 이벤트 -> 다음 날 아침 생존 판정 -> 수면 정신력 회복 +5`다. 따라서 다른 이벤트가 없다면 수면 한 번의 정신력 최종 순변화는 `-5`다. 허기와 갈증의 최종 순변화는 각각 `-20`, `-30`이다.

빈사 상태에서 체력 0으로 진행하는 치명적 수면은 즉시 사망 처리되며 일반 수면 감소를 적용하지 않는다.

관련 구현:

- `Assets/_Project/Scripts/Character/CharacterStats.cs`의 `ApplySleepNeeds()`
- `Assets/_Project/Scripts/Shelter/BedObject.cs`의 `AdvanceDayAfterRest()`

## 탐사 감소

### 탐사 시작 고정 비용

탐사를 시작하면 결과와 관계없이 다음 수치가 즉시 감소한다.

| 스탯 | 감소량 |
| --- | ---: |
| 허기 | -15 |
| 갈증 | -10 |

### 탐사 실패 추가 결과

탐사 자체가 실패한 경우에만 별도의 결과 난수를 판정한다.

| 실패 내부 확률 | 결과 | 장비 지참 | 장비 미지참 |
| ---: | --- | ---: | ---: |
| 25% | 체력 피해 | -8 | -18 |
| 25% | 정신력 감소 | -6 | -12 |
| 50% | 추가 스탯 감소 없음 | 0 | 0 |

위 확률은 전체 탐사 확률이 아니라 탐사 실패가 확정된 뒤의 내부 확률이다. 장소 위험도에 장비 지참 시 `-0.15`, 빈사 상태일 때 `+0.15`가 반영된다.

관련 구현: `Assets/_Project/Scripts/Exploration/ExplorationManager.cs`

## 2분기 이벤트 감소

| 이벤트 ID | 조건 | 체력 | 허기 | 갈증 | 정신력 |
| --- | --- | ---: | ---: | ---: | ---: |
| `Q2_SIGNAL_EVT_01` | 진행 선택 | 0 | 0 | 0 | -5 |
| `Q2_SIGNAL_EVT_02` | 진행 선택 | -5 | -5 | -5 | 0 |

`Q2_SIGNAL_EVT_02`는 탐사를 요구한다. 해당 진행에서 탐사 시작 비용까지 함께 발생하면 합계는 체력 `-5`, 허기 `-20`, 갈증 `-15`가 된다. 탐사 실패 결과에 따라 체력 또는 정신력 추가 감소도 발생할 수 있다.

관련 구현:

- `Assets/_Project/Scripts/Events/ShelterCampaignCatalog.cs`
- `Assets/_Project/Scripts/Events/ShelterEventDialogueController.cs`

## 0 도달 후 판정

| 스탯 | 0 도달 결과 |
| --- | --- |
| 체력 | 즉사하지 않는다. 체력 0으로 다음 날 아침을 맞으면 빈사가 되고, 회복하지 않은 채 다시 잠들면 사망한다. |
| 허기 | 0인 상태로 아침을 맞을 때 1차 경고, 다음 아침 2차 경고, 그다음 아침 사망한다. |
| 갈증 | 허기와 동일하게 1차 경고, 2차 경고 후 그다음 아침 사망한다. |
| 정신력 | 사망하지 않지만 0보다 높게 회복할 때까지 탐사를 진행할 수 없다. |

허기와 갈증은 1 이상 회복되는 즉시 경고 단계가 초기화된다. 두 수치가 동시에 치명 단계에 도달하면 먼저 0이 된 수치를 사망 원인으로 사용한다.

관련 구현: `Assets/_Project/Scripts/Character/CharacterStats.cs`

## 제거된 감소 데이터

다음 기능은 2026-08-06 변경으로 제거됐으며 현재 게임 규칙으로 사용하지 않는다.

- 일반 배급 성공 및 실패
- 아껴 먹기 성공 및 실패
- 연속 아껴 먹기 정신력 페널티
- 먹지 않기 허기, 갈증, 정신력 페널티
- 배급 모드 선택 및 저장 데이터
