# 《어제의 지도》 기획 v0.2

최종 갱신: 2026-08-03

## 게임 방향

《어제의 지도》는 재난·좀비 아포칼립스 상황에서 제한된 물자를 확보한 뒤, 벙커에서 장기간 생존하는 3D 탑다운·아이소메트릭 생존 시뮬레이션이다. 주인공 한도윤은 감염 사태 직후 집 안을 직접 돌아다니며 필요한 물건을 벙커로 옮기고, 이후 날짜 단위로 탐사, 생존 관리, 기지 관리, 정신력 관리, 외부 인물과의 상호작용을 이어 간다.

핵심 문장:

- “어제 안전했던 길이 오늘도 안전하다는 보장은 없다.”
- “지도는 그대로지만 위험은 움직인다.”

## 플레이 흐름

1. `MainMenu`: 새 게임 시작 또는 종료
2. `Prologue`: 감염 사태 도입 문장 진행
3. `Scavenge`: 60초 안에 집과 벙커를 왕복하며 물자를 최대한 많이 운반
4. `Shelter`: 날짜 단위로 시설 관리, 배급, 탐사, 이벤트 확인 후 하루 종료
5. 날짜를 계속 진행하며 구조 신호 계열, 합류 계열, 특수·히든 엔딩 조건 판정

날짜 자체는 생존 성공 엔딩 조건으로 사용하지 않는다. 엔딩은 스토리의 최종 선택이나 각 생존 실패 조건이 충족될 때만 진입한다.

## Scavenge 기준

- 플레이어가 한 번에 들 수 있는 임시 운반 아이템은 최대 4개다.
- 4칸이 모두 차면 다른 아이템을 더 주울 수 없다.
- 다용도실의 벙커 입구에 운반 중인 아이템을 내려놓으면 임시 운반 칸이 비워진다.
- 제한 시간이 끝나기 전에 플레이어 본인도 벙커에 들어가야 한다.
- 벙커 밖에 남은 아이템은 최종 보유 물자로 정산하지 않는다.
- 벙커 진입 성공 후 메인 일기에는 이번 파밍으로 확보한 일반 아이템 총 개수만 표시한다.
- 아이템별 정확한 수량과 사용은 Shelter의 창고에서 처리한다.

방별 기준 배치는 다음과 같다.

- 침실: 잠옷, 인형
- 거실: 책, 축구공, 야구방망이
- 주방: 통조림, 물, 식칼
- 욕실: 구급상자
- 다용도실: 만능 수리키트, 기타, 벙커 입구

라디오는 구조신호 계열 핵심 아이템이지만 확보 방식은 아직 확정하지 않았다. 후보는 2일 차부터 12일 차까지의 탐사 등장 확률을 높이는 방식과, 지하 벙커 기본 설비로 배치하는 방식이다.

## Shelter와 일기장

벙커 생존은 날짜 단위로 진행한다. 하루에는 탐사 1회, 일반 이벤트 1회, 고정 스토리, 자유 행동, 취침 후 다음 날 진행이 포함된다.

일기장은 행동 처리용 만능 UI가 아니라 기록 UI다. 역할은 다음처럼 분리한다.

- 일기장: 상태, 스토리, 이벤트 결과, 탐사 결과 확인
- 지하 벙커 창고: 아이템별 보유 수량 확인과 아이템 사용
- 지하 벙커 외부 출입구: 탐사 지도 씬으로 이동
- 탐사 지도 씬: 탐사 장소와 장비 선택, 장소별 판단 기록 현황 확인
- 창고의 판단 기록 책: 3분기 판단 기록의 전체 내용 열람

일기장 카테고리는 `메인 일기`, `이벤트`, `탐사 기록` 세 개다.

## 생존 스탯과 아이템

기본 생존 스탯은 체력, 배고픔, 갈증, 정신력이다. 배고픔과 갈증은 경고 단계를 거쳐 사망 판정으로 이어질 수 있으며, 정신력 0 상태는 탐사 불가 상태와 정신력 이벤트에 영향을 준다.

아이템은 다음 역할로 구분한다.

- 배고픔 회복: 통조림
- 갈증 회복: 물
- 체력 회복: 구급상자
- 정신력 회복: 인형, 책, 축구공, 기타
- 무기: 식칼, 야구방망이
- 기지 수리: 만능 수리키트
- 엔딩 진행: 라디오
- 함정 아이템: 잠옷
- 기록물: 판단 기록 책

판단 기록 책은 일반 생존 물자 총 개수에 포함하지 않는다.

## 탐사와 이벤트

탐사는 장소 선택과 장비 선택을 포함한다. 지도 보유 여부에 따라 선택 규칙이 달라지며, 장소별 판단 기록 현황을 탐사 지도에서 확인한다.

탐사 지역 후보는 편의점, 병원, 경찰서, 주택가, 통신소 또는 방송국이다.

이벤트는 일반 이벤트, 루트 보조 이벤트, 핵심 루트 이벤트로 나뉜다. 분류는 체력, 아이템, 정신력, 기지, 외부, 엔딩, 히든 이벤트를 기준으로 한다.

엔딩 계열은 구조신호 계열, 합류 계열, 특수 엔딩, 히든 엔딩을 기준으로 잡는다. 1분기에는 일반 이벤트와 계열 추첨, 2분기에는 계열 진행과 통과 판정, 3분기에는 최종 방향 선택, 4분기에는 최종 엔딩 산출을 목표로 한다.

현재 Shelter 연결 기준:

- 1분기: 2~12일차 문 앞 T 이벤트의 선택 점수로 구조신호 또는 합류 노선을 정한다.
- 2분기: 선택된 노선의 사건 3개를 날짜마다 진행하며, 거절 2회 시 반대 노선으로 전환한다.
- 3분기 구조신호: 4일간 방송 단서를 기록한 뒤 군 주파수 또는 두 번째 주파수를 직접 선택한다.
- 3분기 합류: 4일간 생존자 공동체 또는 붉은 완장에 통조림·물을 지원한 뒤 지원 횟수와 무관하게 직접 합류 대상을 선택한다.
- 최종 엔딩: `마지막 주파수`, `문을 열어준 밤`, `낯선 사람들과`, `붉은 완장`.
- 생존 실패 엔딩: 굶주림, 탈수, 치명상 원인의 `마지막 생존 기록`.
- 날짜 자체에는 상한이나 자동 생존 엔딩이 없다.

## 확정된 조작

- 한도윤 좌클릭: 선택
- 바닥 우클릭: 목적지 이동
- 시설 좌클릭: 접근 후 자동 상호작용
- `E`: 근거리 즉시 상호작용
- 마우스 휠: Perspective 카메라 확대·축소
- `ESC`: 열린 시설·탐사 UI 닫기
- `WASD`: 보조 이동
